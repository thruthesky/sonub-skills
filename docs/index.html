      The skills
      
    
      Each skill is a standard folder with a SKILL.md — the instructions an agent reads — plus a small Python tool. Nothing to sign up for.
      

    
      
      
      
        
      
          
      gp
      
          
      All your work on a GitHub Project board
      
        
      
        
      Talk to your agent in plain words and it manages your GitHub Project board with the gh CLI — then reads the result back to confirm.
      
        
        
          
      • Issues: create, edit, move between columns, close, reopen, comment
        • 
          
      • Kanban columns: add, rename (cards stay), reorder, colour
        • 
          
      • Screenshots and videos attached to issues
        • 
          
      • TODO checklists inside an issue, with progress
        • 
          
      • Assign people and invite collaborators
        • 
          
      • A board per project with /gp init <board URL>
        • 
        
      
        
      Try saying
      
        
        
          
      • “What's on my plate?”
        • 
          
      • “Move #12 to Review”
        • 
          
      • “Add ‘update the docs’ to its TODO”
        • 
          
      • “Add a column Urgent at the front”
        • 
        
      
        
      Needs a free GitHub account, the gh CLI and Python 3.8+.

      popup
      
          
      Explain every hard word where the reader meets it
      
        
      
        
      Hover a technical word on any page or doc of your project — or tap it on a phone — and a small card explains it: meaning, plain words, examples, source code, related terms and a “learn more” link to another page of your own project.
      
        
        
          
      • One glossary JSON is the source of every explanation, in every language you ship
        • 
          
      • A drop-in popup.js and popup.css — no framework, no build step
        • 
          
      • Finds terms in plain text by itself; phrases, “?” buttons and link previews by hand
        • 
          
      • Keyboard, phones (bottom sheet), right-to-left languages and dark mode
        • 
          
      • An audit that finds jargon in your docs with no explanation yet
        • 
          
      • For READMEs on GitHub: a GLOSSARY.md and links that show the meaning on hover
        •

      Give the whole team the same skills
      
      
      Commit this to your repository's .claude/settings.json. When a teammate opens the project in Claude Code and trusts the folder, the marketplace is added and the plugins are installed for them.
      
    
      
    
      {
  "extraKnownMarketplaces": {
    "sonub-skills": {
      "source": { "source": "github", "repo": "thruthesky/sonub-skills" }
    }
  },
  "enabledPlugins": {
    "gp@sonub-skills": true,
    "cc-skill@sonub-skills": true,
    "popup@sonub-skills": true
  }
}
      
  
      

  
      
    
      Update and remove
      
    
      
      
      
        
      UpdateRemove
      
        
          
      Claude Code
            claude plugin marketplace update sonub-skills && claude plugin update <plugin>@sonub-skills
            claude plugin uninstall <plugin>@sonub-skills
      
          
      Codex · Gemini CLI · Copilot CLI
            Run the same curl … | tar line again.
            Delete the skill folder.
      
              
      
      
    
      
    
      <plugin> is gp, cc-skill or popup. Check what is installed with claude plugin list.
      
  
      

      


      
  
      
    
      Questions
      
    
      
      What is an Agent Skill?
      
      A folder with a SKILL.md file that tells an AI agent when and how to do a task, plus the scripts and notes it needs. It is an open standard (agentskills.io), so the same folder works in many agents.
      
    
      
    
      
      Every project or this project only?
      
      “Every project” installs the skill once for all projects on your computer. “This project only” keeps it inside one repository; with the Claude Code plugin it is written to .claude/settings.json, so teammates get it too.
      
    
      
    
      
      Why is the plugin called cc-skill and not claude-skill?
      
      Claude Code reserves plugin names that start with claude- for Anthropic. The plugin is cc-skill; the skill inside keeps its name, so you still type /claude-skill.
      
    
      
    
      
      Is it free? Where does my data go?
      
      Free and MIT-licensed. The skills run on your computer with your own tools: gp talks only to GitHub through your gh login, claude-skill reads the public Claude Code docs and CHANGELOG, and popup works only on your own files.
      
    
      
    
      
      It doesn't show up after installing. What now?
      
      In Claude Code, run /reload-plugins in the open chat or start a new one. In other agents, start a new session so the skill folder is read again. You can also just ask your agent: “is the gp skill installed?”
